### 🧠 Psychophysiology, EEG & Research Tools

- **[Web-Based Artifact Annotation Tool](https://www.google.com/search?q=https://github.com/username/eeg-annotator)** (_EEG Data Processing_): An interactive browser tool for visual inspection and manual artifact rejection in EEG time-series, built to eliminate the need for desktop software during initial data cleaning.

- **[Drag-and-Drop Stimuli Sequence Builder](https://www.google.com/search?q=https://github.com/username/sequence-builder)** (_Experimental Design_): A visual constructor for researchers to design emotional picture viewing tasks, allowing custom timing configurations (fixation, stimulus, ITI) and outputting presentation-ready sequences.

- **[Affective Picture Database Dashboard](https://www.google.com/search?q=https://github.com/username/affective-database)** (_Data Science_): Statistical dashboard for querying standardized emotion datasets, filtering images based on normative valence and arousal ratings for precise experimental matching.

- **[Grand Average EPN & LPP Viewer](https://www.google.com/search?q=https://github.com/username/erp-viewer)** (_ERP Visualization_): Interactive visualization tool for pre-computed Grand Average ERPs designed for rapid visual inspection of early posterior negativity and late positive potentials across conditions.

- **[AffectiveSync](https://affective-sync.pages.dev/)** (_Multimodal Emotion_): Client-side neural network application utilizing computer vision to extract facial blendshapes frame-by-frame and correlate micro-expressions with autonomic emotional dynamics.

- **[Facial Expression Recognition System](https://www.google.com/search?q=https://github.com/username/masters-thesis)** (_Master's Thesis / Computational Neuroscience_): Automated system focusing on neural networks and pattern recognition designed for clinical and research environments to analyze human emotional responses via facial expression classification.
